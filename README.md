# SIMULATING-COOK

面向中式家常菜的互动模拟厨房。用户选择 AI 指导伙伴后，在一人称奶油风厨房中完成食材选择、预处理、下锅、火候调味、装盘检查和原理复盘；另有完整的自由实验与 A/B 双分支对照。

## 核心功能

- 55 种食材按畜肉、禽肉、水产、叶菜、瓜茄、根茎、菌菇豆制品和主食辅料分类。
- 53 种食材使用用户收集或已有摄影图，统一裁切为 800×800 WebP；未提供图片的食材使用分类视觉占位。
- 33 种调料按基础咸味、酸味、甜味、香辛料、油脂类和辅助类分组。
- `/cook/` 是标准菜谱实训主入口，提供 25 道菜、99 个标准步骤、可控变量、风险判定、AI 教练和结果复盘。
- `/cook/3d/` 是 Three.js + Rapier3D 沉浸式演示，支持第一人称碰撞漫游、移动端摇杆和六工位交互。
- `/cook/classic/` 保留原 2.5D 一人称厨房；经典模式继续提供“小焰、知味、阿鲜”三位伙伴。
- 3D 实训可选择“夏小弥”或“奶龙”作为跟随导师，实时提示清洗顺序、切配中断、火候窗口和糊锅风险。
- 清洗与切配必须持续按住，松开暂停并保留进度；3D 实训采用普通、良好、完美、糊锅四档结果。
- 指导流程按伙伴与食材、预处理、下锅、火候调味、装盘、复盘七阶段推进，只展示当前可用操作。
- 55 种食材均有预处理检查、安全熟度、目标化料理命名和复盘规则；8 种主推食材拥有更细的形态与照片状态。
- 伙伴可随时切换“流程指导”和“交流对话”；流程指导本地运行，对话优先调用真实 LLM，失败时标记为本地知识库回答。
- 菜谱实训对食品安全错误强制阻断，对口味、火候和时长偏差允许试做，并把纠错与偏差写入复盘。
- 菜谱教练优先调用 DeepSeek，超时、限频、未配置或断网时自动使用本地知识库；AI 不参与评分或步骤推进。
- 语音播报使用浏览器 Web Speech，默认关闭，可朗读当前步骤、安全提示、教练回答和最终点评。
- 完成后自动保存实验结果，并可一键把有限实验摘要带入厨友讨论区。
- 每种食材只显示真正适用的处理动作，并标注目的、时机和底层原理。
- 三段式厨房覆盖水槽、砧板和炒锅，支持点击移动与桌面拖拽。
- 动态任务清单会推荐清洗、切配、控水和入锅步骤，但不限制自由探索。
- 厨房顶部常驻五步实验流程，并提供“现在怎么做、也可以、暂不建议”和状态阅读说明。
- 点火后温度每 250ms 更新，熟度持续变化，可暂停、继续和关火记录。
- 首次进入提供三步引导，可随时关闭或重新观看。
- 水花、切配、蒸汽和滋啦反馈由本地粒子与 Web Audio 合成，支持静音。
- 厨友交流中心提供实时大厅、分类讨论、图片、实验摘要、回复、点赞、举报和管理员审核；Supabase 配置见 `supabase/README.md`。
- 模拟表面水分、pH、盐负荷、淀粉水合、蛋白质凝固、氧化、保形和热量穿透等状态。
- 每一步记录“操作前状态 → 操作 → 操作后状态 → 原理 → 跨食材迁移”。
- 可开启“先预测再揭晓”，只比较预测与实际变化，不评分、不判定失败。
- 可从任意状态复制 B 分支；A/B 独立撤销和保存，并识别是否只改变了一个变量。
- 目标提示只列出可调整变量，不直接替用户生成做法。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`。菜谱实训位于 `http://localhost:3000/cook/`，3D 演示位于 `http://localhost:3000/cook/3d/`，2.5D 经典厨房位于 `http://localhost:3000/cook/classic/`。

若重新生成了 `recipe-data.json`，执行 `npm run recipes:risks` 补齐安全与质量风险元数据。

## 验证

```bash
npm run lint
npx tsc --noEmit
npm test
npm run build
```

首次运行浏览器端流程测试前安装 Playwright Chromium：

```bash
npx playwright install chromium
npm run test:e2e
```

Playwright 会设置 `NEXT_PUBLIC_COMMUNITY_DEMO=true`，让社区用例使用本地演示数据，避免匿名登录限频影响完整回归。

## 生产构建

项目使用 Next.js 静态导出，前端可直接部署到任意静态托管平台：

```bash
npm run build
```

静态文件输出到 `out/`，可部署到任意静态托管平台。

社区和在线 AI 使用 Supabase；未配置时，菜谱实训、一人称厨房和本地知识问答仍可完整使用。DeepSeek 通过 Supabase Edge Function 的 `GUIDE_AI_BASE_URL=https://api.deepseek.com/v1`、`GUIDE_AI_MODEL=deepseek-chat` 和仅保存在服务端 secrets 的 `GUIDE_AI_API_KEY` 启用。具体部署见 `supabase/README.md`。

## 内容与模拟边界

- 内容偏中式家常菜，面向已有基础、希望理解原理并迁移判断的用户。
- 短时盐水腌、干盐腌、氧化、酶失活和静置可以模拟。
- 长期发酵、熟成和长期腌制只解释原理与安全边界，不提供操作模拟。
- 实验记录保存在浏览器 `localStorage`；version 1 数据会自动迁移，旧实验不会丢失。
- 菜谱实训和一人称厨房进度保存在当前浏览器，刷新后可继续；菜谱 version 1 本地进度会自动迁移到 version 2。
- 3D 实训结果通过 Supabase 匿名身份云同步；2.5D 与自由实验继续不评分。
- 当前不提供语音输入、跨设备菜谱账号或多人联机；菜谱进度只保存在当前浏览器。
- 模拟不是实际菜谱或食品安全指导；现实烹饪需结合食材种类、厚度、锅具、设备与中心温度判断。
